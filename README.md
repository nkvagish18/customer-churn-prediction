# Customer Churn Intelligence

An end-to-end machine learning project to predict customer churn,
explain risk factors, and recommend potential retention actions.

## Project Status

Day 1: Project setup and initial data inspection.

## Dataset

IBM Telco Customer Churn dataset.

Download:
https://www.kaggle.com/datasets/blastchar/telco-customer-churn

Place the extracted CSV inside `data/raw/`.

## Tech Stack

- Python
- Pandas and NumPy
- Matplotlib and Seaborn
- Scikit-learn
- Jupyter Notebook
- Streamlit (planned)

## How to Run

Create and activate a virtual environment, install the dependencies
from `requirements.txt`, and launch Jupyter Notebook.

## Project Structure

- `data/`: datasets
- `notebooks/`: analysis and experiments
- `src/`: reusable Python modules
- `models/`: saved models
- `reports/`: project figures and reports
- `tests/`: automated tests
